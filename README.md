# Uperf Game Turbo (骁龙 8 至尊版 专属定制版)

> [!IMPORTANT]
> **专机专精声明**  
> 本项目基于 **[yinwanxi/Uperf-Game-Turbo](https://github.com/yinwanxi/Uperf-Game-Turbo)**（作者：Matt Yang / 吟惋兮）精简与二次开发。  
> **仅针对一加 13T（Snapdragon 8 Elite）专属定制，不支持其他任何Soc，理论上你可以在其他同8E设备上尝试使用，不保证有效**

## 一、 项目背景与修改概述

原版 Uperf-Game-Turbo 是一款优秀的用户态性能调度器，但为了兼顾数十款历史芯片与厂商特性，包含了大量冗余配置与复杂的安装嗅探脚本，且默认策略偏向极端激进（如全应用兜底性能档、触屏 4 秒超长提频）。

本项目结合 **一加 13T 硬件特性（台积电 3nm 2+6 Oryon 核心架构）及 类原生系统（crDroid Android 17）** 并不智能的默认调度问题，对调度进行了精简与重构：在确保游戏绝对满帧运行的前提下，大幅削减日常发热，显著提升综合续航。
本项目仅为满足本人强迫症式的续航焦虑与在类原生安卓系统下尽可能恢复原厂colorOS系统性能的愿景做出微调，不建议任何人尝试，你要真想试试也无妨（~~傲娇说是~~）

## 二、 核心修改与定制特性

### 1. 纯粹专机专精，极致轻量化
- **剔除 120+ 冗余芯片配置**：彻底删除所有除 8E 以外的任何芯片的配置文件与安装检测代码；
- **全自动静默部署**：精简 `setup.sh`，剔除音量键等待与复杂分支判断，安装时直接下发目标 8E 专属配置文件；
- **纯净调度环境**：保持调度器自身的高效与轻量，零冗余后台开销。

### 2. 触屏响应时间调优（4.0s 优化至 2.0s）
- 原版在 `modules.switcher.hintDuration` 中设置了 `"touch": 4.0`（4 秒提频窗口），导致日常轻触屏幕阅读时 CPU 也会长时间处于超大核高频空转状态。
- 将全局 `"touch"` 调整为 **`2.0` 秒**：
  - **游戏场景**：玩家连续操作间隔通常在 0.5~1.5 秒，2.0 秒足以保证连续操作期间全核频率死锁不回退，零掉帧、极度跟手；
  - **日常场景**：滑动后超大核仅驻留 2 秒即迅速回落低频省电状态，日常浏览信息流与发热显著改善。

### 3. 类原生三级分档调度（`perapp_powermode.txt`）
打破原版“未指定应用一律性能档”的激进设定，建立三级梯度流转机制：

| 档位分类 | 策略设定 | 覆盖应用范围 |
| :--- | :--- | :--- |
| **省电档 (`powersave`)** | 功耗上限锁死 1.0W，限制极速升频 | 类原生桌面启动器、系统设置、时钟、计算器、联系人、拨号、文件管理、日历、录音机；玩机工具 (Thanox / KernelSU / LSPosed / HMA / DevCheck / InstallerX)；短视频 (抖音 / 快手，8E硬件硬解高刷视频毫无压力) |
| **均衡档 (`balance`)** | 功耗 3.0W~8.0W，能耗比最优 | 相机应用 (`com.oplus.camera` 等保证取景合成流畅)、Google Play 商店、微信、QQ、B站、酷安、Chrome、淘宝等所有日常三方应用（兜底 `* balance`） |
| **性能档 (`performance`)** | 放开功耗与频率限制，大核全开 | 王者荣耀、原神、崩坏：星穹铁道、绝区零、鸣潮、和平精英等主流竞技/大型游戏列表 |
| **极速档 (`fast`)** | 极限算力释放，翻倍 Margin | Geekbench 5/6、安兔兔、CPU/GPU Burn 压测工具 |
| **熄屏规则 (`- powersave`)** | 灭屏即锁死 1.0W | 熄屏瞬间进入深度低功耗，亮屏解锁瞬间毫秒级切回前台应用档位 |

### 4. 开机全自动接管
- 在 `initsvc.sh` 与 `powercfg_main.sh` 中将开机初始化模式由原版的 `balance` 改为 **`auto`**，开机即启动多模自适应流转，无需手动打开 Scene 或终端执行命令。

### 5. 内置 3 分钟低电量守护进程（`battery_monitor.sh`）
无需依赖第三方调度应用或外部框架，模块内部集成了轻量级电量状态机：
- **检测机制**：开机后常驻后台，每 180 秒（3 分钟）例行检查一次电池电量与电源连接状态，几乎 0 额外耗电；
- **低电量锁定**：当电量 $\le 20\%$ 且未处于充电状态时，自动向状态文件写入 `powersave`，强制锁定省电档，并弹出系统通知提示；
- **充电/恢复解锁**：当接入充电器或电量恢复 $> 20\%$ 时，自动解除锁定并恢复 `auto` 全自动智能调度；
- **双稳态锁存**：仅在状态切换瞬间触发与通知，例行轮询期间保持绝对静默，杜绝通知轰炸。

## 三、 安装与使用

### 安装环境要求
- **机型**：一加 13T（OnePlus 13T，代号 `pagani`）
- **SoC**：高通骁龙 8 至尊版（Snapdragon 8 Elite / SM8750）
- **Root 环境**：KernelSU / KernelSU-Next / Magisk / APatch
- **冲突排查**：**安装前请务必停用或卸载 `fas-rs`、其他第三方 Uperf 或限频模块**，避免双调度冲突！

### 刷入方法
1. 在 Release 下载或本地打包生成 `Uperf-Game-Turbo-sdm8e-Custom.zip`；
2. 在 Root 管理器（如 KernelSU Next）中选择 **从本地安装**，选择该 zip 包；
3. 刷入过程约 2 秒完成，刷入后**重启手机**即可；
4. 开机后可查看 `/sdcard/Android/yc/uperf/uperf_log.txt` 验证调度运行状态。
